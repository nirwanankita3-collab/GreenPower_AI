GreenPower AI — Energy Consumption & Optimization Analytics
Project Overview

GreenPower AI is a data analytics project focused on analyzing building-level energy consumption and identifying patterns that can support data-driven energy optimization decisions.

Objectives
Analyze energy consumption across buildings.
Calculate total and average energy consumption.
Identify missing values in the dataset.
Compare energy usage across buildings.
Generate building-wise summary reports.
Present findings using a Power BI dashboard.
Tools & Technologies
Python: Pandas for data analysis
SQL: SQL queries for data analysis
Power BI: Dashboard and data visualization
CSV: Dataset and summary reports
Key Results

Based on the current project analysis:

Dataset contains 1,200 records and 8 columns.
Total energy consumption is approximately 689,297.9 kWh.
Average energy consumption is approximately 574.41 kWh per record.
No missing values were found in the dataset.
Building-wise energy summaries and a graph were generated.
Project Files
GreenPowerAI_Energy_Dataset.csv — Energy dataset

GreenPower Final Dashboard.pbix — Power BI dashboard
building_energy_summary.csv — Building-wise summary report
building_energy_graph.png — Generated graph
GreenPower_AI_Dashboard_Screenshot — Dashboard screenshot, if included
How to Run
Install Python 3 and Pandas:
pip install pandas

Download or clone this repository.
Ensure the dataset CSV and energy_analysis.py are in the same folder.
Run the analysis:
python energy_analysis.py

The building-wise summary report will be saved as building_energy_summary.csv in the current working folder.
Conclusion

This project demonstrates the use of Python, SQL, and Power BI to analyze energy consumption data, generate building-level summaries, and communicate findings through data visualization.
