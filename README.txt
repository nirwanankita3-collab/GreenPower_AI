GreenPower AI – Energy Consumption & Optimization Analytics

Project Overview

GreenPower AI is a data analytics project that analyzes building energy consumption, solar generation, occupancy, and temperature data to identify useful energy usage patterns.

Objectives

- Analyze energy consumption across buildings.
- Compare energy usage on weekdays and weekends.
- Study the relationship between temperature, occupancy, and energy consumption.
- Analyze solar energy generation.
- Identify unusual energy consumption patterns.
- Present insights through an interactive Power BI dashboard.

Tools and Technologies

- Python
- Pandas, NumPy, Matplotlib
- PostgreSQL and SQL
- Power BI
- Excel and CSV

Project Workflow

1. Load the energy dataset.
2. Check missing values and clean the data.
3. Store and analyze data using PostgreSQL.
4. Perform exploratory data analysis using Python.
5. Create charts and summary reports.
6. Visualize important KPIs and trends in Power BI.

Key Results

- Dataset contains 1,200 records and 8 columns.
- Total energy consumption: approximately 689,297.9 kWh.
- Average energy consumption: approximately 574.41 kWh per record.
- No missing values were found in the dataset.
- Building-wise energy summaries and a graph were generated.

Project Files

- data/: Dataset files
- sql/: SQL queries
- notebooks/: Python analysis script
- dashboard/: Power BI dashboard files
- reports/: Summary CSV and generated graph

Conclusion

This project demonstrates how data analytics tools can be used to understand energy consumption patterns and support data-driven energy optimization decisions.
